# 🔐 Intelligent Mobile App for Data Breach Detection

An intelligent Flutter-based mobile application that helps users detect email data breaches and predict email risk using heuristic analysis and real-time breach verification APIs.

---

# 📱 Features

✅ Real-time Email Breach Detection  
✅ Heuristic-based Risk Prediction  
✅ Lightweight & Fast Performance  
✅ Client-side Privacy Protection  
✅ Entropy-based Email Analysis  
✅ User-friendly Interface  
✅ API-based Breach Verification  
✅ Works Offline for Risk Prediction  

---

# 🛠️ Tech Stack

## Frontend
- Flutter
- Dart

## Backend
- Python Flask

## APIs
- LeakCheck Public API

## Tools & IDE
- Android Studio
- VS Code
- Git & GitHub

---

# ⚙️ How It Works

1. User enters an email address
2. System validates email format
3. App performs:
   - Risk Prediction
   - Breach Detection
4. Results displayed instantly

---

# 🧠 Risk Prediction Parameters

The application checks:

- Username Length
- Digit Ratio
- Special Characters
- Entropy Score
- Domain Type

Based on these features, the system classifies the email as:

- Safe
- Medium Risk
- High Risk

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/KeertiKK01/INTELLIGENT-MOBILE-APP-FOR-DATA-BREACH-DETECTION-.git
```

## Go to Project Folder

```bash
cd INTELLIGENT-MOBILE-APP-FOR-DATA-BREACH-DETECTION-
```

## Install Dependencies

```bash
flutter pub get
```

## Run Flutter App

```bash
flutter run
```

---

# 🔧 Backend Setup

## Install Dependencies

```bash
pip install flask requests
```

## Run Backend Server

```bash
python app.py
```

### Backend URLs

Localhost:
```bash
http://127.0.0.1:5000/
```

Android Emulator:
